# ADR 0002 — OPA decides, the gateway does not reimplement the policy

## Status

Accepted.

## Context

The allow, deny and approval rules are the security case. Duplicating them in Python would let the two copies drift.

## Decision

`policies/authz.rego` is the only policy. The gateway posts the input document to OPA and obeys `decision`. If OPA cannot be reached, the decision is deny.

## Consequences

`opa test policies/` is part of CI. Changing a rule without a Rego test is how a control silently disappears. The Python tests check that the gateway treats deny, needs_approval and an OPA outage as not-allow.
